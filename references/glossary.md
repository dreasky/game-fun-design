# 术语表

> `[存疑]` = 这条没站稳，引用时说明它悬着。

## 快乐门类（窄定义体系）

| 中文 | 英文 | 含义 |
|---|---|---|
| 学习快乐 / 乐趣 | fun | **窄义**：识别、内化并自动化新模式的整个过程带来的奖励。本知识库中 fun 专指此项 |
| 秩序快乐 | — | 混乱变有序的可见成果流带来的愉悦 |
| 张力快乐 | — | 有价风险下的下注与幸存带来的愉悦 |
| 身体快乐 | — | 手感、节奏、操作韵律 |
| 归因 | — | 诊断前判断该设计供给的是哪种快乐；归因错则调音方向相反 |

## 核心概念

| 中文 | 英文 | 含义 |
|---|---|---|
| 模式 | pattern | 可被识别、可被内化的规律；一种秩序、一种带变奏的重复 |
| 吃透 `[存疑]` | grok | 出自 Heinlein《异乡异客》。含义未定——"看穿系统即离场"还是"成为其中一员并爱上它"，见 `core-model.md` §3.3 |
| 三层理解 | — | 理智理解 → 直观理解 → 深刻理解（grok）；是否严格递进未定 |
| 噪音 | noise | 玩家无法从中提取模式的信息 |
| 可学习带 | — | 噪音与已知模式之间、学习快乐发生的区间 |
| 复杂度硬顶 | — | 认知上限。超出后玩家只能动用意识层硬算，症状是"烧脑但没意思"。阈值因人而异 |
| 阅历棘轮 | — | 玩家玩过越多同类游戏，同一设计的保质期越短，越需要新颖 |
| 保质期 | — | 学习快乐的寿命：模式自动化后即告终止 |
| 自我观察的成长 | — | 练习期成为 fun 的前提；缺了它练习塌成刷子 |
| 回合密度 | — | 单位时间能转几轮学习循环；学习效率的刻度。游戏区别讲解的本质：可反复行动 + 可观察变化 |
| 阈值可调 | — | 把"难度因人而异"变成设计手段（《蔚蓝》Assist Mode） |
| 表达层 / 表达约束 | — | 作品想传递的情感体验。与归因（机制）正交；双向：痛苦作约束（别调平），情感作吸引力（卖点） |
| 核心动词 | core verb | 玩家高频重复执行的那个判断性动作 |
| 双端失效轴 | — | 诊断单元。两端各是一种病，中间是健康带，附旋钮 |
| 退化策略 | degenerate strategy | 在绝大多数局面下都最优、使其他选择失去意义的解法 |
| 空重复 | — | 单次无成果、无决策、无学习的重复。病不在"重复"，在三条出路都没走 |
| 定价 | — | 用惩罚给行动附加代价，使重复动作变成决策 |
| 纯化 / 混合 | — | 失败成本归零＝纯化学习快乐（蔚蓝）；给失败定价＝混入张力（黑魂） |
| 剥壳测试 | — | 拿掉美术／剧情／音效／社交／数值，看玩法还剩什么 |
| 探索快乐 | — | fun 的近亲：同一"识别→理解"认知线，作用于一次性独特信息（地点/故事），探明即失效 |
| 探明未知 / 有所得 | — | 探索快乐的两层：认知层（一次性）vs 物质层（可累积、复利） |
| 语义密度 | — | 手摆内容给的东西：每个地点讲一个独特小故事，PCG 做不出 |
| 兴趣点密度 | — | 探索的供给：视野内 2–4 个钩子，3 是经验锚点（`[存疑]`） |
| 可见但未解 | — | 探索钩子的要求：看得见但不剧透；满屏问号是探索快乐的杀手 |
| 决策—执行距离 | — | 玩家决策到被执行之间隔的距离；决定身体快乐类型（操作韵律→动作爽感）与代入感强弱 |
| 统帅幻想 | — | 表达层"掌控/征服"极性：指挥游戏的核心吸引力，与"田园梦/温馨"的宁静极性相对 |

## 变量源与寿命

| 中文 | 英文 | 含义 |
|---|---|---|
| 魔法阵 | magic circle | 游戏规则划出的圈：圈内由设计师定义，圈外是现实 |
| 破圈 | — | 玩家不再只在圈内玩，开始造新的圈；把玩家本身变成会学习的深源 |
| 模式空间 | — | 一个系统里可学的东西的总量。保质期 ≈ 模式空间 ÷ 学习速度 |
| 变量源 | — | 模式空间的来源。接一个源之后变量自己会长，不用设计师持续供给 |
| 深源 / 浅源 | — | 判据：**这个源会不会因为玩家的学习而变化**。会＝深（对手、社群、玩家自己的历史）；不会＝浅（随机、PCG） |
| 幽灵车手 | ghost | 用玩家自己最佳记录生成的对手。罕见地同时做到深源 + 完全可读 |
| 透明测试 | — | 把机制明白告诉玩家，他还觉得有意思吗？会＝博弈层（供给 fun）；不会＝偏差层（只供给"回来"） |
| 博弈层 / 偏差层 | — | 博弈层是给玩家的模式，偏差层是绕过玩家的模式 |
| 规则类涌现 | — | 组合深度的第二种原料：异质规则共享接口、相互改写咬合，产生设计师没逐一写下的组合行为（Balatro）；三条件 = 共享接口 / 能改写 / 链式传递 |
| 接口集中 / 反制分散 | — | 规则涌现靠接口集中（咬合），平衡靠反制分散（多路独立克制）。只集中 = 退化策略，只分散 = 无涌现 |

## 厌倦、动机与迁移

| 中文 | 英文 | 含义 |
|---|---|---|
| 厌倦 | boredom | 大脑在找新信息却找不到。是"该教的还没教完"时的失败信号 |
| 教完模型 / 长寿模型 | — | 教完＝内容与教学序列匹配，学完走人是完成；长寿＝接深源让模式空间自己长 |
| 新数据 / 新经历 | — | 新数据填充已有语法（大脑渴求）；新经历要求重建模型（大脑抗拒） |
| 组块化 | chunking | 大脑把信息压成块以省力。"感官超负荷"的真正含义是组块失败，不是信息多 |
| 构件判据 | — | 动机的合格线：玩家学会的每个模式都要成为后续模式的构件。学完用不上＝死知识 |
| 学习迁移三层 | — | ①学习循环的形状 ②执行层/手感 ③素材。改①＝换了个游戏，改②＝要 unlearn，改③＝纯新数据 |
| 成本 vs 没收 | — | 作废玩家已内化的语法：在续作里是成本（有预期缓冲），在补丁里是没收（无处可退） |
| 内化段 / 应用段 | — | fun 的两段：内化段到自动化为止；应用段拿旧模式组合生成新解，本身是独立快乐 |
| 组合复用 / 捷径复用 | — | 复用旧知识的两种价值：组合复用拼出新解（强快乐）；捷径复用直接映射跳过重学（弱快乐，作节奏喘息） |
