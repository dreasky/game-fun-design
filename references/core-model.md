# 核心模型

> 目录：§1 归因 · §2 表达与目标 · §3 学习快乐 · §4 秩序 · §5 张力 · §6 跨门类 · §7 迁移 · §8 度

## 〇、一页总览

| 层 | 一句话 | 旋钮/入口 |
|---|---|---|
| **归因** | 先判断供给哪种快乐：学习/秩序/张力/身体 | 归错则调音方向反（§1） |
| **表达** | 作品想传递什么情感；痛苦可能是表达载体 | 别把表达当 bug 调平（§2.1） |
| **目标** | 教完还是长寿 | 决定"玩家走了"算不算失败（§2.2） |
| **学习快乐** | 识别→内化→自动化→应用；保质期≈模式空间÷学习速度 | 加变量、升维、接变量源（§3） |
| **秩序快乐** | 混乱变有序的可见成果流 | 让成果更可见、节奏交还玩家（§4） |
| **张力快乐** | 有价风险下的下注与幸存 | 调惩罚重量，别调数量（§5） |
| **跨门类** | 重复的三条出路：成果/决策/学习 | 一条都不走才是病（§6） |
| **迁移** | 改动落在学习循环/执行层/素材 | 续作里改是成本，补丁里改是没收（§7） |

诊断任何一条前，先过 §2 的表达与目标；诊断流程与 14 条轴见 `diagnose.md`。

## 一、归因：先判断供给的是哪种快乐

本知识库守**窄定义**：`fun` 专指**学习型快乐**。其他令人愉快的东西不叫 fun，各立门类、各自归因。

**为什么必须归因**：不同门类衰减时该调的旋钮方向相反——学习快乐衰减要加变量，秩序快乐衰减时加变量是帮倒忙。归因错了，调音方向就是反的。

| 门类 | 快乐来自 | 衰减时调什么 | 典型品类 |
|---|---|---|---|
| **学习快乐**（fun，窄义） | 识别、内化并自动化新模式 | 加变量、升维 | 策略、Roguelike、格斗 |
| **秩序快乐** | 混乱变有序的可见成果流 | 让单次成果更可见、节奏交还玩家 | 模拟器、整理类、放置 |
| **张力快乐** | 有价风险下的下注与幸存 | 调惩罚**重量**，别调数量 | 搜打撤、生存、Roguelite |
| **身体快乐** | 手感、节奏、操作韵律 | 打磨反馈质感 | 音游、动作 |

审美/叙事/社交**不在表中** `[存疑]`——它们是**表达层**载体（§2.1），不是供给快乐的机制；用"旋钮+失效轴"建模从开始就错了。

> 修正：原把审美/叙事/身体/社交统称"非乐趣愉悦"、断言主要是"掩盖玩法空洞"——错，秩序与张力能独立撑起品类，遮羞布是用法问题不是门类属性；原把审美/叙事/社交当"空门类"——错，它们是表达层载体。

**诊断第一步永远是归因**，不是找病。

## 二、定位：表达与目标（元规则）

> 本节压在所有轴之上。诊断前先定这两件事，否则轴会把作品的优点当 bug。

### 2.1 表达：作品想传递的情感体验

**归因回答"供给什么快乐机制"，表达回答"传递什么情感体验"——两条正交的轴。** 同样是"重复劳动"：星露谷是田园悠闲，异星工厂是效率成就，受苦游戏是挣扎。机制一样，体验完全不同。

表达双向：

| | 负向：约束 | 正向：吸引力 |
|---|---|---|
| 内容 | 痛苦、挣扎、焦虑 | 悠闲、温馨、田园梦、浪漫 |
| 作用 | **别调平它** | 玩家因它而喜欢，是卖点 |
| 案例 | 黑魂、蔚蓝 | 星露谷、动森 |

- **负向（约束）**：后面的轴默认"快乐最大化"，这个默认常常是错的。痛苦若是表达载体（黑魂的挫败、蔚蓝的攀爬与对抗焦虑），把难度调到快乐最优点，等于把作品要说的话删掉。**轴给出的是快乐最优位，不是应该在的位置**；轴只用来衡量代价，不用来决定去留。
- **正向（吸引力）**：归因解释不了"玩家为什么喜欢它"——星露谷的田园梦、动森的温馨、全战/骑砍的统帅幻想。这一层不供给可测量的快乐，它传达情感，是卖点。
- **正向有极性**：宁静/逃避（田园梦、温馨）↔ 掌控/征服（统帅幻想、权力感）。同一套机制底座，换个表达就是完全不同的游戏。
- **表达可做成玩家自选项** `[存疑]`：群星开局自选伦理/物种/政体——玩家不是"玩着玩着变成某帝国"，是开局就选了自己的表达；它同时提供"我为什么要玩"的动机入口（§3.8）。"自选表达"与"设计师单向传递"是否同一种东西、边界在哪，未展开。

**审美/叙事/社交是表达层的主要载体** `[存疑]`——这就是它们没有旋钮、没有失效轴的原因；用门类工具去建是南辕北辙。

由此产生一种**合法的诊断结论**：

```
这条轴偏了，但偏得对——痛苦是表达载体，不建议调。
代价：<会流失哪类玩家 / 会牺牲哪种快乐>
可选：给阈值调节手段（§3.4），让不吃这套的玩家能绕过
```

### 2.2 目标：教完，还是长寿

一句能当尺子的话：**厌倦是告诉你已经失败了的信号**——但前提是"该教的还没教完"。

定义：**好游戏能在玩家停止游戏之前，把应该提供的每一样东西都教给玩家。** 在这个定义里，玩家学完走人**不算失败**，作品功德圆满。

| | **教完模型** | **长寿模型** |
|---|---|---|
| 目标 | 内容量与教学序列匹配，教完即终 | 接不可穷尽的变量源，模式空间自己长 |
| 玩家走了 | 成功——他学完了 | 失败——源没接住他 |
| 失败信号 | **教完之前**就腻了 | 腻了 |
| 典型 | 传送门、蔚蓝、多数单机 | EVE、塔科夫、竞技品类 |

传送门通关三小时，没人说它寿命短。

**完整判据**：在你该教的东西教完之前玩家出现厌倦，那是失败；教完之后他走，那是完成。

**玩家流失的两种情绪**：厌倦＋挫败＝设计失败；厌倦＋胜利感（"我完全打败它了"）＝可能是作品完成。

**"往哪调"的三个依据**：归因（供给哪种快乐）+ 表达（想说什么）+ 目标（教完还是长寿）。三者夹出来的位置才是"度"。

## 三、学习快乐（fun，窄义）

### 3.1 定义与两段

乐趣是**大脑识别、内化并自动化一个新模式的整个过程**中释放的愉悦信号，是学习的生理奖励。游戏本质是被娱乐化包装的教学工具，教的是抽象化、形式化的模型。"好玩"不是加进去的属性，是学习过程本身的副产品。支持它的一条论断：**不能锻炼大脑的游戏很乏味**。

**fun 分两段，自动化不是终点：**

| 段 | 内容 | 快乐来源 |
|---|---|---|
| 内化段 | 识别 → 理解 → 自动化（手熟了不用想） | 识别、内化新模式 |
| 应用段 | 拿已自动化的旧模式，组合生成从没见过的新解 | 应用所学本身 |

- 内化段到自动化为止——这就是 §3.2"保质期"管的那段。
- **应用段是独立快乐，不是内化段的收尾**：巴别塔圣歌把两段摆得清清楚楚——认字（内化段）与当翻译官（应用段）是两种不同的爽。
- 应用段自己也是一条轴：太简单＝爽但速腻，太难＝累；对象从"认模式"换成"用模式"，与可学习带（§3.4）同构。

> 修正：原把 fun 终点定在"识别出模式的那一刻"→ 练习期也算 fun（§3.6）→ 自动化后还有"应用段"（独立快乐），终点延到"自动化 + 组合应用"。

### 3.2 保质期

**学习快乐有保质期**：模式被自动化之后，它不再产生学习快乐。玩家的退出台词是"我已经弄清楚了，我不需要再练习这个任务了"。

> **保质期 ≈ 模式空间大小 ÷ 玩家学习速度**

标准案例：**井字棋**——锻炼大脑但锻炼得极其有限，几局就被吃干。对照组**围棋**——同样完全形式化、规则同样一页纸，却活了两千年。所以病因不是"形式化"，是模式空间相对学习速度太小（详见 `variable-sources.md` §1）。

**怎么把保质期拉长**：供给内容（线性成本）或接不可穷尽的变量源（一次性设计，之后自己长）。整套变量源理论在 `variable-sources.md`。

两条修饰：

- **阅历棘轮**：保质期不是常数。玩家学到的模式越多，游戏就得越新颖才抓得住他——玩过越多同类游戏，同一套设计的保质期越短。→ **判据**：同一份新手引导，对新玩家是可学习带，对老玩家是已知模式。这不是设计好坏，是受众阅历；做老玩家市场必须提高起点或提供快进。
- **练习延长**：练习能让一个游戏保鲜一段时间；供给条件见 §3.6。

> 修正：原写"模式一旦被完全掌握，同一模式不再产生乐趣"——错在把 fun 的衰减当成**快乐整体**的衰减；模拟器与搜打撤证明学习快乐用完后，秩序快乐与张力快乐仍可继续供给。"玩腻"要先归因是哪一路断了。

### 3.3 grok（吃透）`[存疑]`

**方向未定，暂不作为依据使用。** 两种解读，解释力不同：

- **吃透即离场**：grok = 看穿规律、稳定产出最优解 →"这个系统对他死了"。支持它的是玩家的退出台词"我已经弄清楚了，不需要再练这个了"。
- **吃透即归属**：grok 一词出自 Heinlein《异乡异客》，原义是彻底了解某物之后**成为其中一员、甚至深深爱上它**。支持它的是格斗、围棋、Dota 高手吃透系统后仍投入数千小时。

两者可以并存：**fun 在此结束，人继续留下靠的是张力、社交、表达等别的快乐。** 这个调和目前只是推测，等更多材料或案例定夺。

### 3.4 噪音 — 可学习带 — 已知模式

```
噪音（学不会）  ←  可学习带（学习快乐在这里）  →  已知模式（无聊）
 太复杂/反馈不可读            信息量刚好              已自动化
 反应：挫败、放弃                                    反应：厌倦、划水
```

挫败与无聊是同一问题的两端——都是"没在学东西"，但解法相反。这是本知识库所有**双端失效轴**的原型（见 `diagnose.md`）。

**复杂度硬顶**：认知有硬上限。语言学对照——从句嵌套太深的句子会变成病句，人得动用缓慢而有意识的逻辑大脑才能苦心思索出答案。

→ **判据**：乐趣发生在**直觉可及**的复杂度内。超出后玩家仍解得开，但那是动用意识层硬算，症状是"烧脑但没意思"，与"看不懂要干嘛"是噪音端的两种不同病。

> **和模式空间划清界限**：硬顶讲的是**单次决策的复杂度**（这一步要同时权衡几个量），模式空间讲的是**总量**（整个系统有多少东西可学）。围棋单步决策在直觉可及范围内，总量却大到穷尽不了——两者独立，别混用。

**但阈值因人而异——不能一刀切：**

- 存在大量玩家专门追求慢思考硬算——EU4、Factorio、矮人要塞、重策桌游、各类受苦游戏。他们不是在忍受苦役。
- 阈值还受**题材与作者表达意图**影响（§2）。
- 两种解释待定 `[存疑]`：**(A)** 专家的演算已被练成直觉，覆盖范围远大于新手，对他们那不是硬算；**(B)** 求解本身是另一门快乐，需另立门类。倾向 A 为主。
- **设计动作**：不要赌所有人共享同一个阈值。**给阈值调节手段**（《蔚蓝》Assist Mode 是范本），或明确选定受众并承认会流失另一批。

### 3.5 学习循环

```
察觉变量 → 形成假设 → 试 → 反馈 → 修正模型 → 内化 → 自动化 → 需要新变量
```

每一环都可能断：察觉不到变量（反馈不可读）／试的成本太高（惩罚过重、重试太慢）／反馈延迟或被随机性污染（学不到因果）／自动化后无新变量（转成空重复）。

**新数据 vs 新经历**——大脑要的不是同一样东西：

| | **新数据** | **新经历** |
|---|---|---|
| 作用 | 把已有模式具体化，填充已掌握的语法 | 要求建立一个全新系统 |
| 大脑反应 | 渴求，永不知足 | **常常不喜欢**，因为要重建模型，会引起混乱 |
| 例子 | Roguelike 加新道具、资料片 | 加一整套新系统、续作重做核心机制 |

大脑不喜欢多余的工作，所以它一上来就**组块化**——先把信息压成块。"感官超负荷"这个矛盾说法的真正含义是**组块失败**，不是信息量大。

> **判据**：扩展内容优先给新数据（填充已有语法）；新经历只在旧语法已经自动化、玩家开始腻的时候给。给早了是混乱，给晚了是无聊。

### 3.6 练习期的五个供给条件

**游戏区别于讲解的本质，在于它给"可反复行使的行动 + 可观察的变化"。** 一个设计如果一次性就能讲完、不需要玩家反复行动，它是讲解不是游戏。由此推出：**回合密度（单位时间能转几轮学习循环）就是学习效率的刻度**——没有只有一个回合的游戏。

练习**不会自动**变成 fun。分界线是：**能不能自我观察到成长**。缺了这个，练习立刻塌成刷子。

《蔚蓝》是教科书样本，拆出五条：

| # | 条件 | 说明 |
|---|---|---|
| 1 | **重试成本趋零** | 死到重来不足一秒，无读盘无动画；学习循环转多快取决于这个数 |
| 2 | **失败可归因** | 物理完全确定，同样输入同样结果，"刚才哪一下错了"永远有答案 |
| 3 | **单位任务足够小** | 一个房间 = 一个技巧组合 = 一节课，不是一大坨 |
| 4 | **进步肉眼可见** | 房间过了、死亡数降了、动作从卡顿变连贯，三层都能自我观察 |
| 5 | **阈值可调** | Assist Mode：把"因人而异"变成设计手段，而不是听天由命 |

五条缺任何一条，练习都会往空重复滑。

### 3.7 学习快乐的必要条件

1. **状态可读**——玩家能看清当前局面
2. **规则可预期**——同样输入给同样结果（随机可作用于输入，不可污染因果）。*限定*：这是学习快乐的条件；追求长寿时会主动牺牲它一部分——接外部变量源就是拿可读性换寿命（`variable-sources.md` §5）。牺牲多少是一条轴上的选择，不是失误。
3. **选择有意义**——存在多个非劣选项，且优劣随局面变化
4. **进步可感知**——玩家能察觉自己变强了
5. **可掌握但未掌握**——落在可学习带内，且在直觉可及的复杂度内

> 这五条是**学习快乐**的条件，不是"好玩"的通用条件。秩序快乐不需要第 3 条。

### 3.8 动机：可学 ≠ 想学

上面所有条件回答的都是"能不能学"，没有一条回答"**为什么要学**"。这是一种独立的厌倦：模式空间够大、可读、有梯度，玩家就是不感兴趣。棒球的 RBI 统计就是例子——记住了也不能成为任何后续行动的构件。

**合格线判据**：

> **玩家学会的每个模式，都要成为后续模式的构件。**

学完就用不上的模式是死知识，玩家能察觉它是死的，因而不想学。

这条顺手解释两件事：

- **银河城/魂系为什么有成长感**——每个新能力都是后续解谜的构件，学一个开一片
- **数值成长为什么空**——数值不是构件，它不改变你**能做什么**，只改变你能扛多久

**优秀线未定**——"什么样的复用算优秀"需要更多案例才能下结论，这里刻意留空。

**复用有两种价值**：

| | **组合复用** | **捷径复用** |
|---|---|---|
| 干什么 | 旧构件拼成从没见过的新解 | 旧知识直接映射，跳过重学 |
| 例子 | 翻译：用诗人倒装习惯转述另一族的话；Balatro 拿 Joker 规则拼 build | 放逐者族群的同义关联 |
| 快乐 | 强——应用所学本身 | 弱——只是省力、舒服 |

- **组合复用**是"应用段"（§3.1）的核心动作，供给强快乐。
- **捷径复用**不是劣质——它出现在玩家学累的时候，是**喘息奖赏**、节奏调节：终于能拿旧知识开个捷径，不必重新解读。两种价值各有其位，不是高下之分。

### 3.9 探索快乐：fun 作用于独特信息

玩家嘴里的"探索快乐"是复合体验，拆开是两层：

| 层 | 本质 | 归属 | 失效方式 |
|---|---|---|---|
| **探明未知** | 认知层：读懂、理解这个地点/故事 | **fun 近亲** | 一次性，探明即失效 |
| **有所得** | 物质层：拿到资源、能力 | 视所得类型归秩序/张力/进步可感知 | 可累积，**复利** |

**第一层是 fun 的近亲**：引擎同为"识别→理解"的认知线，分野只有两处——作用对象（fun 是可复用模式，探索是一次性独特信息）、失效方式（fun 自动化后衰减，探索探明即失效）。同一栋楼第二次走进去没惊喜，但学会的机制能反复用。

反证：塞尔达的**呀哈哈**是纯"探明"（无实用价值），玩家仍乐此不疲地找——证明"探明未知"能独立供给快乐，两层可拆。

**媒介不限于空间**：塞尔达/僵毁的探索发生在**地图**上，但"一次性独特信息"也能由**语言/叙事**承载。巴别塔圣歌里，破译一个字 = 同时读懂一段世界信息——战士管教士叫"不洁之人"，一个称呼就编码了族群的价值观、偏见、历史。

> 一个动作同时供给两路快乐：破解一个字，既是 fun（识别一个可复用的语言模式），又是探索（探明一段一次性的世界信息）。两路快乐失效方式独立——语言学完了 ≠ 世界读完了。

**"有所得"是探索快乐里不衰减的那一半，也是探索型游戏长寿的真正引擎**：所得会复利——拿到钥匙→去更深处→得更多。若探索只给"探明"，地图探完就死。

**探索快乐还能做 onboarding 的缓释垫**：它不需要先学机制就能供给，所以能垫在新手最脆弱的头半小时——复杂度硬顶还没碰到，探索快乐先接住。群星开局（单科学家探异常）把"体系多、上手慢"的 4X 缓释成平缓探索。任何"上手慢"的游戏，都能用探索/整理/建造这类零门槛快乐当前置（`diagnose.md` 轴 2）。

**空间探索的供给判据**（三条是空间媒介的；语言/叙事媒介的判据还没建——"可见但未解"可类推到"未解的字"，"兴趣点密度"是空间特化的）：

1. **兴趣点密度**：视野内 2–4 个钩子，3 是经验锚点（`[存疑]`，随地形可见度与受众调）。这是 `diagnose.md` 轴 3 从"机制选项"到"空间选项"的推广。
2. **钩子"可见但未解"**：看得见（否则找不到），但不剧透（否则"探明"的快乐被杀死）。满屏问号图标把答案剧透，探索退化成打卡清点。
3. **奖励发成钥匙，不是强度**：所得应"解锁更多探索"（耐力↑→爬更高→探更多），而非"碾压当前内容"（最强装备→地图贬值）。前者让探索复利，后者让探索贬值。

## 四、秩序快乐

快乐来自**混乱变有序的可见成果流**。清扫、整理、拆装维修、流水线优化。

四个供给要素：

1. **熵减可见**——脏→净是最易读的反馈，进度不靠数字告诉你
2. **零失败风险**——做不完只是没做完，不会惩罚；无风险故重复即休息
3. **节奏自控**——快慢由玩家定
4. **微变奏**——每个对象略有不同，仍有极低成本的预测—验证

**核心判据**：重复本身不上瘾，**重复带来的稳定成果流才上瘾**。完全一致的重复（节拍器、瓷砖）几秒即被大脑过滤成背景。

衰减时**不要加变量**——那是学习快乐的药。正确动作是让单次成果更可见、把节奏还给玩家。

---

## 五、张力快乐

快乐来自**有价风险下的下注与幸存**。搜打撤（塔科夫）、生存、Roguelite 的深潜。

### 5.1 惩罚给行动定价

**惩罚的作用不是劝退，是给行动定价；定了价，重复动作才变成决策。**

无掉落惩罚时，搜箱子是吸尘器作业——多搜一个只有正收益，没有理由停手，所以那不是决策，是劳动。加上"死了全掉"之后，多搜一个箱子变成一次下注：再待 30 秒的期望收益，对上被人堵门的概率。撤离路上最紧张，正因为身上的东西此刻价值最高。

### 5.2 惩罚是一条轴，不是一个开关

- 太轻 → 行动免费 → 无决策 → 空重复
- 太重 → 不敢试错 → 学习循环断裂 → 变成背板

中间那段才是张力带。往哪调取决于要供给哪种快乐，再叠加 §2 的表达约束。

## 六、跨门类判据

### 6.1 重复的三条出路

重复动作本身无罪。它难受，是因为三条出路一条都没走：

| 出路 | 机制 | 代表 |
|---|---|---|
| **有成果** | 每一次都产生可见变化 | 模拟器 |
| **有决策** | 每一次都是有代价的下注 | 搜打撤 |
| **有学习** | 每一次都在验证一个假设 | 蔚蓝、策略、Roguelike |

**判据**：一次重复动作如果自身不产生可感知的成果，它就必须换来别的东西——而"换来的东西"越远、越不可控，重复就越难受。

刷子游戏难受，是因为单次没成果、多做也不付代价、且节奏被掉率与体力他控。

### 6.2 纯化还是混合

同样是高难度，蔚蓝被叫"舒服"，黑魂被叫"受苦"，原因是门类配方不同：

- **蔚蓝**：失败成本压到零 → **纯化学习快乐**（张力被刻意剥掉，死亡不惩罚，只是重来）
- **黑魂**：跑尸体、掉魂 → **学习 + 张力混合**（给失败定了价）

**判据**：想纯化学习快乐，就把失败成本压到零；想混入张力，就给失败定价。**两条都成立，不存在"哪个难度设计更好"**——选哪条取决于要哪种体验，以及要表达什么（§2）。

### 6.3 决策—执行的距离

指挥类游戏（RTS、全战、骑砍）共享"学习 + 张力 + 秩序"的机制底座，差别在**玩家的决策到被执行之间隔了多远**：

| 档 | 距离 | 身体快乐类型 | 代入感 | 代表 |
|---|---|---|---|---|
| 远 | 下令后单位 AI 执行 | 操作韵律（框选、编队、微操） | 低 | 卡拉克、RTS |
| 中 | 分层：战略决策 + 战术指挥 | 观赏（军团对冲）+ 操作 | 中 | 全面战争 |
| 近 | 决策 = 亲自执行 | 动作爽感（砍杀、冲锋） | 高 | 骑马与砍杀 |

- 距离越近，身体快乐越"动作化"、代入越强；距离越远，纯策略快乐越纯。
- **全战的分层**是把"决策—执行"显式拆成两层，把学习循环的"决策→反馈"拉长放大：战略判断在战术层被亲手验证。
- 可推广到更广品类：卡牌＝纯决策（远），动作/魂类＝决策即执行（近）。

> 修正：原以为"远距离指挥没有身体快乐"——错，RTS 的操作本身是身体快乐（操作韵律），只是类型不同，不是没有。

## 七、学习迁移：续作与补丁

老玩家带着已内化的语法进来。改动落在哪一层，决定他是"在学新东西"还是"被没收资产"。

### 7.1 三层

```
① 学习循环的形状   撞墙 → 拿到能力 → 回头破解 → 精准操作练习
                   改这层 = 它变成另一个游戏

② 执行层 / 手感    hitbox、速度、治疗机制、资源换算
                   改这层 = 玩家要 unlearn，有摩擦，但只要新的够好就能接受

③ 素材            地图、敌人、道具、角色
                   改这层 = 纯新数据，最安全
```

**丝之歌**：动 ②③ 不动 ①——大黄蜂的 hitbox、移动、攻击、治疗全变了（治疗改成可移动中施放但一次烧光丝条，逼你进攻回资源），"第一个真正的挑战是忘掉骑士"。摩擦真实存在，难度也有争议，但学习循环的形状没动，老玩家的核心能力仍然迁移得过去。

### 7.2 关键不在改哪一层，在改动发生在哪里

| | **续作里改** | **补丁里改** |
|---|---|---|
| 玩家预期 | 本来就是来学新东西的 | 我买的就是那个东西 |
| 旧资产 | 前作还在，随时能回去 | 被没收，无处可退 |
| 可承受度 | 高，摩擦而已 | 低，资产没收级反应 |

> **判据**：作废玩家已内化的语法，**在续作里是成本，在补丁里是没收**。前者摊在"学新东西"的预期里，后者没有任何缓冲。

**杀戮尖塔 2** 是这条判据的实证，但要看清信号：首发 97% 好评，后来跌到 31%，中间是两波与设计无关的 review bombing（其中一波因制作人员名单）。**真正的设计信号只有一条**——运营期的平衡改动**移除了玩家发现的无限连击**，引发大规模反弹。那不是续作问题，是补丁问题，删掉的是玩家在设计师没管的空地上造出来的圈（`variable-sources.md` §6）。

### 7.3 续作特有的张力

续作面对的是**已经 grok 了前作的玩家**：学习速度极快（新数据消耗得也快），但对语法变动的容忍度最低。它得同时满足"给得更多"和"别改根基"。

只给新数据 → 被骂换皮卖全价；给新经历 → 被骂不如前作。出路是**语法保留 + 在它之上加一层新维度**，做加法而不是替换。

## 八、关于"度"

设计里少有绝对禁令，多数是**度的把握**。但说不清就归给"度"，等于放弃诊断。

**度不是玄学，度是轴上的位置，由三个依据夹出来：归因（§1）+ 表达（§2.1）+ 目标（§2.2）。** 所以诊断统一用**双端失效轴**：写清两端各是什么病、中间带是什么、旋钮在哪，再由三个依据决定停在哪一格。
