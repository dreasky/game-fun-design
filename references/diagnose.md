# 诊断流程：双端失效轴

> 本文件不是禁令清单，是**调音台**。每条轴两端都是坑，中间是带。诊断 = 判断偏向哪端 + 说清往哪调。
> 流程：症状 → 三问 → 描模式结构 → 上轴 → 可执行动作。

## 轴速查

| 轴 | 左端 | 右端 | 调 |
|---|---|---|---|
| 1 信息量 | 噪音（学不会） | 已知模式（无聊） | 减变量 / 加变量、升维 |
| 1b 受众阅历 | 起点太高 | 起点太低 | 补引导 / 提高起点 |
| 2 变量投放 | 太慢 / 一次太多 | 太快 | 提前投放 / 放慢+拆分 |
| 3 选择结构 | 退化策略 | 选项过载 | 加条件 / 减选项 |
| 4 反馈可读性 | 察觉不到 | 过载 | 缩短延迟 / 分层呈现 |
| 5 随机性 | 随机主导 | 全确定 | 随机作用于输入，不污染因果 |
| 6 进步可感知 | 感觉不到成长 | 成长全自动 | 能力里程碑 / 挂玩家技能 |
| 6b 重试成本 | 太贵 | 无重量 | 压缩重试 / 给失败定价 |
| 7 惩罚重量 | 行动免费 | 不敢试错 | 定价 / 降单次损失 |
| 8 节奏控制权 | 全他控 | 全自控 | 交还收手权 / 加压力 |
| 9 单次成果可见度 | 空重复 | 决策疲劳 | 让每下可见 / 留低谷 |
| 10 包装占比 | 玩法空洞 | 毫无包装 | 补玩法 / 给包装 |
| 11 变量封闭度 | 封闭（速腻） | 开放（劝退新手） | 接变量源 / 加可读性中介 |

规则空间的退化策略 → 轴 3b 的平衡操作手册（先结构后数值）。

## 症状速查表：从玩家原话反查

| 玩家原话 | 指向 | 轴 |
|---|---|---|
| "太简单了" | 几分钟就吃透，模式空间太小（井字棋） | 轴 1 已知模式端 |
| "太简单了，都是在重复" | 模式空间可能不小，但**变化太慢**，他在看到深度之前就下了结论 | 轴 2 左端 |
| "太难了" | 完全提取不到模式，全是噪音 | 轴 1 噪音端 |
| "太难了，太快了" | 模式变化快于内化速度，失控 | 轴 2 右端 |
| "烧脑，但没意思" | 解得开，但要动用意识层硬算 | 轴 1 噪音端（第二种病） |
| "我完全打败它了" | 模式全部自动化，保质期到期。**带胜利感，不带挫败感** | 保质期（`core-model.md` §3.2） |
| "东西是多，但我不感兴趣" | 可学 ≠ 想学：学到的东西不是后续的构件 | **动机，当前无对应轴** |

两条读法：

- **"我完全打败它了"要先问目标**：教完模型里这可能是**完成**而非失败（§2.2）。厌倦＋挫败＝设计失败；厌倦＋胜利感＝可能是作品做完了。
- **最后一行是模型已知的洞**：动机维度目前只有合格线判据（§3.8），没有轴。遇到它别硬套别的轴。

## 步骤

### 0. 三问：供给什么快乐？想表达什么？做完还是做久？

**这一步错了，后面全是反的。**

| 问 | 判断 | 错过的后果 |
|---|---|---|
| **归因** | 用门类表判断供给哪种快乐——学习/秩序/张力/身体。一个设计常同时供给多种（塔科夫＝学习+张力+一层秩序），分别归因、分别上轴，**不要混着诊断** | 调音方向反 |
| **表达** | 这个作品想传递什么情感体验？（§2.1）痛苦若是表达载体，别当 bug 修掉；悠闲温馨若是卖点，它是吸引力来源 | 把作品要说的话当 bug 修掉，或把情感魅力当"玩法空洞" |
| **目标** | 教完还是长寿？（§2.2）教完模型里玩家学完离开是完成，长寿模型里才是失败 | 把做完的作品诊断成濒死 |

归不出任何门类 → 玩法是空的，跳过诊断，转 `ideate.md`。

### 1. 描出模式结构

三句话写清：
- **核心动词**——玩家反复做的那个动作
- **变量**——影响这个动作结果的因素有几个，分别是什么
- **反馈**——做完之后玩家从哪里知道对错，延迟多久

### 2. 上轴定位

按归因结果，走对应门类的轴。每条轴回答两个问题：**偏了哪端**、**证据是什么**。

### 3. 输出可执行动作

每条结论写成三段：

```
症状：玩家在 X 阶段开始划水
定位：轴 1（信息量）偏"已知模式"端——核心动词只有 1 个变量
动作：第 3 关引入 <具体变量>，使原有最优解在 <具体条件> 下失效
```

**禁止**输出"增加多样性""让战斗更有深度""优化节奏"这类无法执行的话。

另一种**合法结论**——偏了但不该调：

```
症状：新手在第 2 小时大量流失
定位：轴 7（惩罚重量）偏"不敢试错"端
结论：偏得对——挫败感是本作要表达的东西，不建议调
代价：流失掉不吃这套的玩家（约定目标受众之外）
可选：给阈值调节手段（辅助模式／可选难度），让另一批人能绕过
```

## 学习快乐的轴

### 轴 1 · 信息量

| | 左端：**噪音** | 右端：**已知模式** |
|---|---|---|
| 症状 | 几分钟就放弃 | 玩得下去但划水 |
| 玩家原话 | "看不懂要干嘛""不知道为什么输" | "我已经弄清楚了""这游戏就是 XXX" |
| 标准案例 | —— | **井字棋**：锻炼大脑但锻炼得极少，几局吃干 |
| 调 | 减变量、加可读性、拆教学梯度 | 加变量、升维、让旧解法失效 |

中间带 = 可学习带。这是所有轴的原型。

**噪音端有两种病，别搞混：**

| | 看不懂 | 烧脑但没意思 |
|---|---|---|
| 玩家状态 | 提取不出模式 | 解得开，但要动用意识层硬算 |
| 原话 | "不知道要干嘛" | "太累了，不想算" |
| 调 | 加可读性、减同时变化的变量 | 降到直觉可及的复杂度，或**给阈值调节手段** |

**阈值因人而异**（EU4／Factorio／受苦游戏的玩家阈值远高于平均），所以"降复杂度"不是唯一解——`core-model.md` §3.4。

### 轴 1b · 受众阅历

| | 左端：**起点太高** | 右端：**起点太低** |
|---|---|---|
| 症状 | 无同类经验的玩家进不来 | 老玩家在教学期就腻了 |
| 调 | 补引导梯度 | 提高起点、提供快进、直接跳过已知模式 |

判据：**保质期长度取决于目标玩家玩过多少同类游戏**（阅历棘轮，§3.2）。同一份新手引导对两类人落在轴的两端——这不是设计好坏，是受众问题，先定受众再判断。

### 轴 2 · 变量投放节奏

| | 左端：**变化太慢／一次给太多** | 右端：**变化太快** |
|---|---|---|
| 症状 | 中期疲软；或教程期劝退、机制记不住 | 玩家跟不上，控制不住局面 |
| 玩家原话 | "都是在重复" | "太难了，太快了" |
| 调 | 提前投放下一个变量；或拆成序列一次只加一个 | 放慢投放，留出内化时间 |

判据：**新变量应在内化刚完成时到达**——早了是噪音，晚了是无聊。

**加什么也有讲究**：优先给**新数据**（填充已掌握的语法），**新经历**（要求重建模型）只在旧语法已自动化时给（§3.5）。搞反了，加内容反而制造混乱。

### 轴 3 · 选择结构

| | 左端：**退化策略** | 右端：**选项过载** |
|---|---|---|
| 症状 | 存在一个几乎永远最优的解，其余选项成装饰 | 选项多但无法比较，玩家随便点 |
| 调 | 给最优解加条件依赖，让它在某些局面变劣 | 减少同时可见的选项，或给出比较维度 |

**这条轴也作用于空间选项**：开放世界的兴趣点密度同样是选择结构——视野内钩子太少（<2）＝迷茫（噪音），太多（>4）＝过载。旷野之息的三角法则就是轴 3 在空间上的应用，甜点值约 3 个（经验锚点，`[存疑]`，§3.9）。

### 轴 3b · 平衡调整的操作手册

当退化策略出现在**规则空间**（一堆卡牌/技能/词条）时，轴 3 只说"偏左端"，这里给"怎么调"的完整流程——它是"规则类涌现"的平衡面（`variable-sources.md` §1）。

**第 0 步 · 确认有"秤"**：所有规则能否换算到同一度量（Balatro 一切折算成"对 chips×mult 的贡献"）？不能 → 先造公共接口，别调平衡。

**第 1 步 · 找退化策略，别凭感觉**：退化不是"某张强"，是"几乎在所有局面都强、且无代价"。检测问句——**"玩家能无限拿资源时会拿什么？"** 答案稳定到少数几张、且无条件区分 → 退化策略。

**第 2 步 · 对退化卡按顺序下刀**（先结构后数值）：

1. **加条件**——"全局 ×2" → "红心牌才 ×2"。把全局强拆成条件强，不伤涌现，首选。
2. **加成本**——更贵/占槽位/耗资源，让它有取舍。
3. **降稀有度**——少见，弱化"指望"。
4. **换接口**——别让它和那个 combo 咬合。动结构，伤涌现，慎用。
5. **砍数值**——**最后手段**：会连锁改掉所有吃它的 combo。

**第 3 步 · 查反制是否独立**：若"贵"和"稀有"两把刀正相关（强牌又贵又稀有），它们是同一把刀。反制维度必须互相独立，才构成兜底网。

**第 4 步 · 验收 = "都有赢面"，不是"一样强"**：目标是消灭全局碾压，让每张牌至少有一个局面是它的最优解。验收问句——**"这张牌在什么局面下我会为拿到它而高兴？"** 答不上来 → 它是装饰，回到第 2 步①加条件。

### 轴 4 · 反馈可读性

| | 左端：**察觉不到** | 右端：**过载** |
|---|---|---|
| 症状 | 不知道自己做对没做对 | 特效／数字淹没关键信息 |
| 调 | 缩短延迟、单独呈现、一次只让一个变量变 | 分层呈现，弱化非决策信息 |

**误诊警告**：玩家看不懂输赢原因时改数值，只是换个看不懂的输法。

### 轴 5 · 随机性

| | 左端：**随机主导** | 右端：**全确定** |
|---|---|---|
| 症状 | 结果无法归因到决策，学不到东西 | 最优解固化，一次算清后无张力 |
| 调 | 随机作用于**输入**（局面、资源），不污染**因果**（同样决策同样结果） | 引入信息不完全或随机输入 |

**正例**：群星的科技抽卡——每次研究完成，从权重池随机抽三个选项供选择。随机作用于**输入**（给什么选项），每个科技的效果确定可预期（不污染因果）。既留"刷出意外科技"的惊喜，又去掉"研究错方向就崩"的焦虑。

### 轴 6 · 进步可感知

| | 左端：**感觉不到成长** | 右端：**成长全自动** |
|---|---|---|
| 症状 | 变强了但没感觉 | 数值代劳，玩家没有"我变强了"只有"号变强了" |
| 调 | 给能力型里程碑（原来打不过的现在能打） | 把成长挂到玩家技能而非数值上 |

### 轴 6b · 重试成本（练习期）

| | 左端：**重试太贵** | 右端：**重试无重量** |
|---|---|---|
| 症状 | 死一次要等读盘/跑图，玩家不敢试，转成背板 | 失败毫无份量，没有"这次一定要过"的紧绷 |
| 调 | 压缩失败到再试的时间；缩小检查点间距 | 加入张力（给失败定价，见轴 7） |

**练习要成为 fun，五条缺一不可**（`core-model.md` §3.6，《蔚蓝》为范本）：重试成本趋零／失败可归因／单位任务足够小／进步肉眼可见／阈值可调。缺任何一条，练习都会往空重复滑。

诊断问句：**玩家能不能自我观察到成长？** 答不上来，这段练习就是刷子。

## 张力快乐的轴

### 轴 7 · 惩罚重量

| | 左端：**行动免费** | 右端：**不敢试错** |
|---|---|---|
| 症状 | 没有理由停手，重复变劳动 | 背板化，玩家只走已知安全线 |
| 调 | 给行动定价（掉落、时限、暴露） | 保留代价但降低单次损失，或提供有限重试 |

核心判据：**惩罚不是劝退，是定价；定了价，重复才变成决策**（§5.1）。

### 轴 8 · 节奏控制权

| | 左端：**全他控** | 右端：**全自控** |
|---|---|---|
| 症状 | 掉率／体力／CD 决定玩家什么时候能玩 | 无外部压力，局面松散无收束 |
| 调 | 把"何时收手"的决定权交还玩家 | 加入时限、逼近的威胁、资源衰减 |

## 秩序快乐的轴

### 轴 9 · 单次成果可见度

| | 左端：**空重复** | 右端：**决策疲劳** |
|---|---|---|
| 症状 | 一次操作几乎无变化，靠计数器累积 | 每一步都要重大判断，无喘息 |
| 调 | 让每一下产生可见变化 | 留出无脑执行的段落作为节奏低谷 |

**重复的三条出路**：有成果／有决策／有学习，一条都不走才是病（§6.1）。

## 跨门类的轴

### 轴 10 · 包装占比

| | 左端：**玩法空洞** | 右端：**毫无包装** |
|---|---|---|
| 症状 | 剥掉美术／剧情／社交后玩法立刻塌陷 | 纯抽象，玩家没有进入动机 |
| 调 | 补玩法层（先归因要供给哪种快乐） | 给主题与感官包装 |

**剥壳测试**：把美术、剧情、音效、社交、数值成长全部拿掉，问剩下的部分玩家在干什么、图什么。

### 轴 11 · 变量封闭度

| | 左端：**封闭** | 右端：**开放** |
|---|---|---|
| 症状 | 可穷尽、易读、易学、**速腻**；只能靠出内容续命 | 不可穷尽、难读、**劝退新手**；但老玩家不走 |
| 代表 | 井字棋、多数休闲手游 | EVE、塔科夫、矮人要塞 |
| 调 | 接一个外部变量源（`variable-sources.md` §3 素材库） | 减少同时暴露给新手的源，或加可读性中介（幽灵、复盘、死亡标记） |

判据：**接外部变量源 = 拿可读性换寿命**。长寿游戏对新手不友好往往不是失误，是选了右端——骂它上手难等于骂它长寿。

诊断问句：**这个设计有几个不可穷尽的变量源？** 零个 → 寿命 = 玩家穷尽模式空间所需的时间，之后只能靠做内容续命。

例外值得抄：**幽灵车手**——深变量源 + 完全可读，两端的好处都占了（`variable-sources.md` §4）。

## 常见误诊

- **把"太难"当噪音端问题**——难度高但可读是好设计；病在**学不到**，不在**打不过**。
- **把腻当内容不够**——加关卡不解决模式已被吃透。先归因：断的是学习、秩序还是张力。
- **把重复当病因**——重复无罪，走轴 7／9 判断它有没有出路。
- **归因错门类**——给秩序型玩法加变量、给学习型玩法加成果流，都是往反方向调。
- **把表达当 bug 修**——没问步骤 0 的问二，就会把作品刻意保留的痛苦当成失误调平。
- **假设所有人共享一个阈值**——"太难了"要先问对谁太难；受苦向作品的目标受众阈值本就高得多。
- **拿蔚蓝的标准要求黑魂**（或反过来）——两者门类配方不同（纯化 vs 混合，§6.2），不存在哪个难度设计更好。
- **把玩家造出来的玩法当 bug 修掉**——修之前先看它有没有变成玩法（`variable-sources.md` §6）。格斗游戏的连段取消当年都是 bug。
- **把程序生成当成长寿方案**——PCG 是浅层变量源，玩家 grok 的是生成器本身。
- **用偏差层机制冒充快乐**——留存曲线还在不等于玩法还活着；过一遍透明测试（`variable-sources.md` §7）。
- **把"做完了"诊断成"要死了"**——教完模型里玩家学完就走是完成。先问步骤 0 的问三。
- **在补丁里作废玩家已内化的语法**——续作里改是成本，补丁里改是没收（`core-model.md` §7.2）。
- **拿聚合评分当设计信号**——评分会被与设计无关的事件污染（杀戮尖塔 2 的两波 review bombing）。看曲线拐点和具体诉求，不看总分。
